# Bill-book

Frontend Web Application for **BP Consultant — Bill Book & Invoice Management System**.

## 🌟 Features
- **1:1 Monochrome Pure Black & White Physical Bill Replica**
- **3-Field Fast Bill Generation** (Company Name, Amount, Service Description)
- **Interactive Live Preview** with A4 Print & PDF Export
- **Full Invoice Editing & Updating**
- **Client & Company Directory** (Add, Edit, Remove clients with autocomplete)
- **3-Year Archive & Ledger** with Year/Month filters & Excel/CSV export

## 🚀 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
